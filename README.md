## What is JobSearch.ai?

JobSearch.ai searches across the public web to help candidates discover jobs matching their role, skills, experience, and location.

It can discover listings from:

- 🏢 Company career pages
- 💼 LinkedIn
- 🔎 Indeed
- 🎓 Unstop
- 🧑‍💻 Internshala
- 💼 Naukri / Foundit
- 👾 Monster
- 🌱 Wellfound
- 🏗️ Greenhouse
- 🚀 Lever
- And other publicly accessible job sources

The system preserves **real job and application URLs** instead of generating fake or Google-search fallback links.

### 🔒 Human-Controlled Applications

JobSearch.ai **never automatically applies for a candidate**.
